# MrSunshisjournal

## Objetivo de la App

El objetivo de esta aplicación es proporcionar una herramienta de seguimiento y registro para los cuidados diarios de mascotas exoticas en particulas cuyos y hamsters. Permite a los usuarios registrar actividades como la alimentación, el cambio de agua, limpieza, y observaciones sobre el comportamiento del hámster. Con esta aplicación, los propietarios de hámsters pueden llevar un control efectivo y detallado sobre la salud y bienestar de sus mascotas.

## Descripción del Logo

El logo de la aplicación presenta la imagen infaltil de un hámster con una pequeña bitácora. Este diseño simboliza la función principal de la aplicación: registrar los cuidados de tu hámster. Los colores utilizados representan la calidez y cuidado, con tonos cálidos que evocan la sensación de bienestar y amor hacia las mascotas.

## Justificación de la Elección del Tipo de Dispositivo, Versión del Sistema Operativo y las Orientaciones Soportadas

- **Tipo de dispositivo**: La aplicación ha sido diseñada para dispositivos **iPhone** debido a su portabilidad y facilidad de uso, lo que la hace ideal para registrar cuidados sobre la marcha. No es necesaria una pantalla grande, ya que las funcionalidades se adaptan perfectamente a las pantallas de tamaño medio de los iPhones.
- **Versión del sistema operativo**: La aplicación es compatible con **iOS 15.0** y versiones superiores. Esta versión ofrece soporte adecuado para los frameworks utilizados (FSCalendar, ActionSheetPicker y CoreData), además de garantizar una experiencia fluida y optimizada.
- **Orientaciones soportadas**: La aplicación soporta las orientaciones **vertical** por facilidad de registro.

## Credenciales para Acceder a la App

Para poder utilizar la aplicación, no se requieren credenciales de acceso. La app está disponible para su uso inmediato después de la instalación. Si se requiere un sistema de autenticación en el futuro, se proporcionarán las credenciales pertinentes en el archivo de documentación.

## Dependencias del Proyecto

El proyecto utiliza los siguientes **frameworks** y **paquetes**:

- **FSCalendar**: Framework utilizado para mostrar un calendario interactivo donde los usuarios pueden registrar los eventos relacionados con el cuidado de su hámster.
- **ActionSheetPicker**: Framework utilizado para facilitar la selección de opciones a través de un *ActionSheet*, ofreciendo una experiencia de usuario intuitiva para seleccionar actividades de cuidado o datos relevantes.
- **CoreData**: Framework de Apple para la gestión de datos persistentes, utilizado para almacenar y recuperar de forma eficiente toda la información registrada sobre los cuidados de los hámsters.
